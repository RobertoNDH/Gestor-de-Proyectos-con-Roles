# Gestor de Proyectos con Roles

Bienvenido al repositorio oficial del **Gestor de Proyectos con Roles**, desarrollado como proyecto final para la formación en Django.

Esta aplicación permite a equipos de trabajo gestionar proyectos, asignar roles específicos a usuarios y realizar un seguimiento de tareas y mensajes internos de manera profesional y segura.

## 🚀 Enlaces Importantes

*   **Aplicación en Vivo:** https://gestor-de-proyectos-con-roles.onrender.com/

## 🛠️ Características Principales

*   **Sistema de Roles y Permisos:** Acceso restringido a proyectos y tareas según el rol asignado a cada usuario.
*   **Gestión de Tareas:** Creación, edición y cambio de estado de tareas asignadas al equipo del proyecto.
*   **Mensajería Interna:** Chat integrado dentro de cada proyecto para facilitar la comunicación del equipo.
*   **Seguimiento Visual:** Gráficos interactivos en tiempo real que muestran el porcentaje de avance de las tareas.
*   **Diseño Premium UI/UX:** Interfaz moderna y adaptable con modo oscuro nativo.

## 🔑 Credenciales para la Evaluación

Para facilitar la corrección y poder probar todas las funcionalidades de la aplicación, existe un entorno de prueba con proyectos, roles y usuarios preconfigurados.

Puedes acceder como **Administrador** utilizando los siguientes datos:

*   **Usuario:** `admin`
*   **Contraseña:** `usuario123`

*(Existen también usuarios de prueba como `laura_dev` o `carlos_front` con la misma contraseña para probar la vista de un empleado normal).*

## 💻 Tecnologías Utilizadas

*   **Backend:** Python 3, Django
*   **Frontend:** HTML5, CSS3, Chart.js
*   **Base de Datos:** PostgreSQL
*   **Despliegue:** Render.com
